# Modelo de Qualidade de Software — Normas ISO/IEC 12207 e ISO/IEC 25010
## Plataforma de Energia Renovável com TOPSIS

---

## 1. Processos de Ciclo de Vida do Software (ISO/IEC 12207)
A norma ISO/IEC 12207 estabelece uma estrutura comum para os processos de ciclo de vida de software. O presente projeto implementa os processos primários:

1. **Processo de Aquisição e Elicitação:** Mapeamento das carências energéticas e identificação dos dados necessários junto às fontes oficiais (IBGE, ANEEL, INPE).
2. **Processo de Fornecimento:** Definição da arquitetura técnica e especificação de requisitos formais.
3. **Processo de Desenvolvimento:**
   - Análise de Requisitos (RF e RNF estruturados);
   - Projeto de Arquitetura de Software (Padrão MVC em camadas desacopladas);
   - Projeto Detalhado (Diagramas UML e modelo relacional);
   - Codificação e Testes Unitários/Integração (Jest, Supertest);
   - Integração do Sistema e Verificação Matemática do TOPSIS.
4. **Processo de Operação e Manutenção:** Containerização Docker, documentação OpenAPI/Swagger e scripts de migração automatizados.
